TPT Energy

Golden-case gallery

The workspace ships reference cases with committed expected results. They are what the test suite compares against, and they are the quickest way to see whether an installation behaves: every command below is a single line and prints numbers you can check against the table.

The fixtures live in test-data/ and are regenerated by the generate-ieee-goldens, generate-solar-goldens, and generate-wind-goldens binaries in the examples/ sub-workspace. The golden-drift CI job fails if a regeneration changes a committed value, so the numbers below cannot rot silently.

Machine-readable, for a script:

A linear DC solution, for a first look at a large case:

tpt-nrg run --system test-data/ieee/ieee57.json --method dc

Format interoperability

Every bundled case round-trips through every writer, and the diff mode is how you check that:

tpt-nrg convert test-data/ieee/ieee14.json --to matpower -o /tmp/case.m
tpt-nrg convert /tmp/case.m --round-trip

MATPOWER cannot carry bus names, so that round trip reports exactly the name fields as removed and nothing else. --round-trip on the native JSON is lossless and prints no differences:

tpt-nrg convert test-data/ieee/ieee14.json --round-trip

Cross-format comparison of two different cases:

tpt-nrg convert test-data/ieee/ieee14.json --diff test-data/ieee/ieee30.json

That exits 1 and lists the first differences by path, for example branches[id=1].rating_mva: 200.0 -> 130.0.

Dispatch and commitment

StudyCommandFixture
Economic dispatchtpt-nrg run --system <case with cost curves> --dispatch 100test-data/golden/dispatch/economic-dispatch-5gen.json
Unit commitmenttpt-nrg run --system <case with cost curves> --committest-data/golden/dispatch/unit-commitment-24hr.json

Both need a merit order: a case whose generators have no cost_curve cannot be dispatched, and the CLI says so rather than inventing an order. The IEEE cases in test-data/ieee/ therefore cover the power flow, fault, and interop paths but not the dispatch ones.

Reproducing the fixtures

cargo run --manifest-path examples/Cargo.toml --bin generate-ieee-goldens
cargo run --manifest-path examples/Cargo.toml --bin generate-solar-goldens
cargo run --manifest-path examples/Cargo.toml --bin generate-wind-goldens
git diff --exit-code test-data   # non-zero means a fixture drifted

Generators round emitted values to 9 decimals so that libm differences between platforms cannot produce false positives.
