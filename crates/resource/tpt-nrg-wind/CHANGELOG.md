# Changelog
All notable changes to this crate will be documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- `WindModel` — log and power-law vertical profiles, Weibull PDF, Weibull-mean power via Gauss–Legendre quadrature.
- `WindTurbine` — cubic or table power curve with configurable thrust coefficient.
- `WindFarm` with three wake models: `JensenPark`, `Frandsen` (rotor-equivalent source, two-zone deficit, partial-rotor overlap), and `EddyViscosity` (explicit cylindrical diffusion march).
- Farm-level power output with kinematic deficit superposition.
- Golden fixtures for all three wake models under `test-data/golden/wind/` (generated by `generate-wind-goldens` from the library itself).
- `substrate` feature cross-validating distribution sampling via `tpt-math-prob-dist`.
- This crate-level `README.md` with crates.io `categories` and `keywords` metadata.

### Changed
- `WindFarm::effective_wind_speeds` now dispatches per `WakeModel` instead of panicking on the unimplemented variants.
- The Jensen deficit uses each turbine's own thrust coefficient rather than a hardcoded 0.8.

### Fixed
- Eddy-viscosity march uses a stability-safe explicit step (the axis-adjacent node is stiffer by ~2×), preventing divergence at large downstream distances.
- `tests/golden.rs` now exercises the thrust coefficient end-to-end through the wake fixtures (previously reported as an unused field).
