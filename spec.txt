## 1. Open Source Declaration

`tpt-energy` is a fully open-source, MIT-licensed computational engine for **macro-scale energy systems, power grids, and renewable integration**. Every crate, every optimization algorithm, and every power flow solver is freely available under MIT OR Apache-2.0.

### Why Fully Open Source for Energy?

The global transition to renewable energy is being bottlenecked by legacy, proprietary grid software.

1.  **The Monopoly Problem:** Power system analysis is dominated by closed-source, exorbitantly expensive tools (PSS/E, DIgSILENT PowerFactory, ETAP, HOMER Pro). Startups, researchers, and developing nations are priced out of grid innovation.
2.  **The Scripting Trap:** Open-source alternatives (MATPOWER, pandapower) are often bound to MATLAB or Python, making them too slow for real-time edge deployment and impossible to compile into standalone, browser-based WebAssembly tools.
3.  **The Device-Grid Disconnect:** Legacy tools treat the grid as a black box. They don't natively integrate with the physics of the devices connected to it (battery chemistry, wind turbine aeroelasticity, solar thermal degradation).

`tpt-energy` solves this by acting as the **Universal System Integrator**. It provides blazing-fast, memory-safe, pure-Rust power flow solvers, dispatch optimizers, and economic models. Because it compiles to WebAssembly, it can run real-time microgrid control logic on edge devices or interactive grid planning tools directly in the browser.

### Why Rust for Energy Systems?

| Requirement | Rust Advantage |
|---|---|
| Real-time Grid Control | Microsecond latency for edge microgrid controllers |
| Massive Sparse Matrices | `tpt-math` sparse solvers for 100,000+ bus power flow |
| Browser-based Planning | WASM compilation for interactive utility dashboards |
| Enterprise Deployment | MIT-only chain, no GPL audit risk for utilities |
| Memory Safety | No segfaults in critical infrastructure control loops |
| Concurrency | Fearless concurrency for parallel scenario analysis |

pub struct PowerFlowSolver {
    pub system: EnergySystem,
    pub method: PowerFlowMethod,
    pub max_iterations: u32,
    pub tolerance: f64,
}

pub enum PowerFlowMethod {
    NewtonRaphson,
    GaussSeidel,
    FastDecoupled,
    DcPowerFlow,
}

impl PowerFlowSolver {
    pub fn solve(&self) -> Result<PowerFlowResult, PowerFlowError> {
        match self.method {
            PowerFlowMethod::NewtonRaphson => self.newton_raphson(),
            PowerFlowMethod::DcPowerFlow => self.dc_power_flow(),
            // ... other methods
        }
    }
    
    fn newton_raphson(&self) -> Result<PowerFlowResult, PowerFlowError> {
        // 1. Build Y-bus admittance matrix
        // 2. Initialize voltage vector
        // 3. Calculate power mismatch (ΔP, ΔQ)
        // 4. Build Jacobian matrix (sparse)
        // 5. Solve J * Δx = mismatch
        // 6. Update voltages and angles
        // 7. Repeat until mismatch < tolerance
    }
}

### License Traps to Avoid

| Domain | GPL/Proprietary Trap | MIT Solution |
|---|---|---|
| Power Flow | PSS/E, DIgSILENT, ETAP (Proprietary) | Pure Rust Newton-Raphson via `tpt-math` |
| Open Source | MATPOWER (MATLAB), pandapower (Python) | Standalone Rust binaries, no runtime dependencies |
| Optimization | Gurobi, CPLEX (Proprietary) | `tpt-math-optimize-general` (MILP/LP solvers) |
| Solar Models | NREL SAM (BSD but C++/Python heavy) | Clean-room SPA implementation in Rust |
| Microgrid | Homer Pro (Proprietary) | Clean-room dispatch and islanding logic |

## 14. Summary

`tpt-energy` is a fully open-source, MIT-licensed, pure-Rust computational engine for macro-scale energy systems:

- **Resource Modeling** — Solar SPA, wind wake models, load forecasting
- **Power Systems** — AC/DC power flow, fault analysis, state estimation
- **Energy Storage** — Battery dispatch, hydrogen electrolysis, thermal storage
- **Microgrids** — Islanding detection, grid-forming control, VPP
- **Dispatch & Economics** — Unit commitment, economic dispatch, LCOE, carbon intensity

All crates maintain the strict MIT chain, leverage the TPT substrates (`tpt-math`, `tpt-engineering`, `tpt-science`), and compile to WebAssembly for browser-based planning and real-time edge control.

No proprietary cores. No GPL traps. No vendor lock-in. Just open source.
