# NREL test fixtures

This directory holds NREL-derived golden data for solar position (SPA) and
clear-sky irradiance validation in `tpt-nrg-solar`.

Current contents:
- `solar-position-spa-golden.json` — see `test-data/golden/solar/nrel-spa-zenith.json`
  for the cross-referenced golden SPA samples.
- `pv-output-derating-golden.json`  — see `test-data/golden/solar/pv-output-derating.json`
  for DC output at standard test conditions with applied thermal derating and
  inverter clipping.
